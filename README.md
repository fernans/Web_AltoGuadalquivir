# Alto Guadalquivir — Municipal Portal (prototype)

Prototype of the municipal portal for the **Mancomunidad del Alto Guadalquivir** (Córdoba, Spain): a static HTML website where each member municipality gets its own portal with a shared structure and design (two examples included: **Montoro** and **El Carpio**, each with *town hall*, *tourism*, *services* and *procedures* sections). It also includes an online-services Flash module, design sketches (PSD), GoLive site templates (`.dwt`) and web reference captures.

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

**Note on security**: for security reasons, some parts of the project may have been edited or removed. (Nothing sensitive was found during the audit; no files were modified.)

## Requirements / How to run

- Pure **static HTML 4.01** pages with a single CSS file (`styles/style.css`) — just open `index.htm` in any browser.
- The *procedures* module is **Flash** (`.swf`): playback requires the discontinued **Adobe Flash Player** (kept for historical/educational reference only).
- The `.dwt` templates and PSD sketches require **Adobe GoLive** and **Adobe Photoshop** respectively.
